⏱ 自动校时工具 time_sync（Go 版 v1.0.0）

通过 NTP 网络时间协议校准电脑系统时钟 · 单文件 exe · 免安装 · 内置 Web 控制面板

三种用法

1
双击即用（推荐新手）：双击 timesync.exe 进入控制台菜单，按 w 即可打开 Web 控制面板，浏览器会自动弹出；面板后台独立运行，关掉那个黑窗口也不影响面板。
2
命令行（适合脚本/计划任务）：在终端里跑 timesync.exe --query 查询偏差，timesync.exe --sync 校正。
3
直接开面板：timesync.exe --web 跳过菜单直接起面板并打开浏览器。

Web 控制面板

启动后地址是 http://127.0.0.1:8765/（若该端口被占用会自动顺延，以控制台打印的地址为准）。面板包含：

区块功能
顶部大数字当前偏差 / 最优参考源 / 晶振漂移，按阈值自动变色
不确定度提示多源交叉验证：显示各可用源的离散程度（±极差/2 ms 与总体标准差）。数据源 ≥2 时才有统计意义，单源时提示「仅单源，无法交叉验证」
预设分组一键切换「国内常用 / 全球 / 教育网 / Windows 默认」时间源组合，省去手动改服务器
偏差趋势最近 20/50/200 次校正的偏差曲线，带容差带与阈值虚线
时间源健康度逐个探测 NTP / HTTP 源，显示可用状态与延迟
时间状态本机 / UTC / 参考时间、当前偏差、是否需要校正、上次校正结果；校时后还会显示「校正后复测偏差」卡片，用红/黄/绿直观反映时钟是否真的对齐（查询动作不显示，避免把 0 误读为已校准）
实时日志后台推送的校准日志（错误/警告分级、可折叠复制）
时间源配置改 NTP / HTTP 服务器、阈值、超时、重试、日志路径、计划间隔；还可开启平滑校时（见下）。「计划任务间隔」填分钟数（默认 60）
回拨确认当校正需要把时钟往回拨超过 60 秒时，面板会先弹出确认框，明确告知回拨幅度与影响（计划任务触发、证书校验、日志时序），确认后才会执行——不会静默倒退时钟
冲突提醒若系统时间服务 w32time 正在运行，校正后会提示「可能周期性覆盖本次校正结果」，建议先停用（菜单 11）
远程访问令牌仅在「远程 / 局域网」打开面板时才需要：timesync.exe --set-token 生成随机令牌写入 配置.ini；之后局域网访问面板地址后加 ?token=... 或请求头带 X-API-Token。本机 127.0.0.1 访问始终免令牌，保持开箱即用
Windows 集成计划任务 / 开机自启 / w32time 开关；计划任务间隔可在面板直接配置，保存后立即生效
怎么关掉面板？在面板右上角点「✕ 关闭面板」即可（面板是独立后台进程，用任务管理器结束 timesync.exe 也可以）。关掉控制台黑窗口不会停止面板。
面板只监听 127.0.0.1（本机回环），不会对外暴露。不想自动开浏览器就加 --no-open。右上角可切换浅色 / 深色主题。

常用命令

# 查询偏差（不改时间）
timesync.exe --query

# 立即校正（校正系统时间需要管理员，会弹 UAC）
timesync.exe --sync

# 每 60 分钟自动校准
timesync.exe --loop --interval 60

# 只起 Web 面板（跳过菜单）
timesync.exe --web --no-open

# 换端口起面板（默认 8765 被占用时会自动顺延）
timesync.exe --web --listen 127.0.0.1:8899

# 注册计划任务（每小时自动校准，无需开着程序）
timesync.exe --install-scheduler

# 开机自动校准
timesync.exe --install-startup

关于权限

「查询偏差」不需要管理员，双击即用。但「校正系统时间」必须管理员/root：程序会在需要时自动弹出 UAC 请求，点「是」即可。
若 UAC 被取消，程序不会消失无响应，而是提示「权限不足」可重试；提权后已自动记住你选的功能，无需再选一次。

面板按钮的提权流程

面板里点「计划任务 / 开机自启 / w32time」这些需要管理员的功能时，不需要自己开管理员控制台——面板会自动用 UAC 提权重开一个后台进程去执行，你只要点「是」授权即可。

1
在面板点开关 → 浏览器弹出 UAC 请求 → 选「是」。
2
程序用带标签的提权重开（例如 scheduler:install / startup:install / w32time:disable），精确执行你刚点的那一项。
3
因为 UAC 有延迟，面板会自己轮询约 12 秒回读最新状态（最多 8 次），状态自动刷新，无需手动刷新页面。
提权重开的进程会继承面板的监听地址和隐藏参数，但不会再弹浏览器；它只执行那一个动作，执行完就退出，不影响已经在跑的面板。

配置文件 配置.ini

放在 timesync.exe 同目录会自动加载。想换时间源、调阈值、改日志路径，改这里就行：

[servers]
ntp  = ntp.aliyun.com, time.windows.com, ...
http = https://www.baidu.com, https://www.qq.com, ...

[sync]
timeout   = 5      ; 单源超时（秒）
threshold = 0.5    ; 偏差小于此值不写时钟
retries   = 2      ; 每源重试次数
log       = 校正日志.txt   ; 相对路径按 exe 所在目录解析；留空=不记录
slew      = false  ; 平滑校时：偏差在 slew_max 秒内分段逼近，避免时钟突跳
slew_max  = 60     ; 平滑校时适用的最大偏差（秒），超过则一次性校正
interval  = 60     ; 计划任务间隔（分钟，>0 生效）

命令行参数优先于配置文件，配置文件优先于内置默认值。日志文件默认就写在 exe 同目录（校正日志.txt），无需手动配置即可记录，偏差趋势与漂移报告（ppm）开箱可用。

「平滑校时」把偏差拆成 10 个小步进逼近目标，适合对时钟连续性敏感的场景；关闭（默认）时是一次性写入，行为更可预测。偏差超过 slew_max 秒时一律一次性校正。
